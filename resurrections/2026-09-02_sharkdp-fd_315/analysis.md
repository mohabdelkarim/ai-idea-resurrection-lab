## Why It Died

When the issue was opened, fd used clap 2, which lacked straightforward support for repeated flags, making implementation cumbersome. Adding multiple pattern handling required complex regex concatenation that the existing codebase did not accommodate. The maintainer workload was already high, and the feature was low priority compared to performance improvements. Consequently, the request stalled and the issue went quiet.

## Why 2026 Changes Everything

fd now depends on clap v4, whose derive macros support multiple occurrences of the same flag out of the box. The regex crate has been updated to efficiently compile and cache multiple patterns. Rust 1.70 introduced const generics and improved iterator ergonomics, simplifying the handling of a vector of patterns. These concrete improvements remove the technical barriers that existed in 2018.

When traversing files, iterate over the compiled regexes and accept a path if any pattern matches, short‑circuiting on the first success.
