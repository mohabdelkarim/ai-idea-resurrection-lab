# Analysis: Add directory chooser

> Streamlit should provide a directory chooser widget to let users select folders directly.

**Why it will work now:** Web browsers now support the HTML input element with webkitdirectory attribute, enabling folder selection.

---

## Why It Died

When the issue was opened, browsers offered limited or inconsistent support for folder selection, making a reliable implementation difficult. The Streamlit core team prioritized data visualization features and had limited bandwidth for UI component expansion. Additionally, the existing file uploader API did not expose a directory‑level abstraction, requiring a substantial redesign that was deemed low priority at the time.

## Why 2026 Changes Everything

Modern browsers now uniformly support the HTML <input type="file" webkitdirectory> attribute, allowing native folder selection across Chrome, Edge, and Firefox. Streamlit 1.30 introduced a pluggable file manager API that can handle directory streams and map them to Python pathlib objects. The Python standard library’s pathlib improvements and async file I/O make processing large directory trees efficient within Streamlit apps.

## Modern Architecture

Introduce a new DirectoryChooser component inheriting from the base StreamlitWidget class. The frontend renders an <input type="file" webkitdirectory> element, capturing the selected folder as a list of File objects. The backend receives this list via the enhanced file manager API, aggregates them into a pathlib.Path representing the root directory, and streams contents lazily using async generators. Configuration options such as recursive depth, file type filters, and preview callbacks are exposed through the component’s constructor. Integration tests exercise the component across supported browsers, and documentation updates illustrate typical use cases like batch processing and dataset loading.
