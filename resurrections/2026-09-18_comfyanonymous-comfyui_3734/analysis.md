# Analysis: [Feature] Support for SD3 ControlNet

> Add a ControlNet node to ComfyUI that leverages diffusers' SD3 ControlNet pipeline integration.

**Why it will work now:** Diffusers 0.23 released a stable SD3 ControlNet API enabling direct pipeline usage.

## Why It Died

When the issue was filed, ComfyUI did not yet support the SD3 model family, making integration of ControlNet cumbersome. The required diffusers PR (8566) was still under review, so the necessary API surface was unavailable. Implementing SD3 ControlNet would have required substantial changes to the node graph system, which the core maintainers lacked time to address. Additionally, the community focus was on stabilizing existing SD1.x and SD2.x workflows, leaving this feature low priority. Consequently the request stalled and the issue went quiet.

## Why 2026 Changes Everything

Diffusers 0.23 (released in 2025) now provides a stable SD3 ControlNet API, eliminating the earlier dependency gap. ComfyUI added native SD3 model loading in version 2.1, simplifying pipeline construction. PyTorch 2.2 introduced optimized kernels for ControlNet, reducing runtime overhead. The HuggingFace Hub now hosts pre‑converted ControlNet weights with standardized metadata, easing asset management. These concrete toolchain upgrades make a robust implementation feasible today.

## Modern Architecture

Introduce a new ControlNetNode class inheriting from the base ComfyNode, encapsulating diffusers' SD3ControlNetPipeline. The node will expose input sockets for the base SD3 model, ControlNet conditioning images, and optional strength parameters. Internally, the node will instantiate diffusers' SD3ControlNetPipeline using the unified Scheduler API, allowing interchangeable samplers. Configuration widgets will be added to the UI to select ControlNet type (Canny, Pose, Tile, Inpainting) and load corresponding weights from the HuggingFace Hub. The node's execute method will batch preprocess conditioning images, invoke the pipeline, and return the generated latent for downstream nodes. Error handling will surface missing model warnings via ComfyUI's logging system. Finally, unit tests will mock the diffusers pipeline to verify node integration without heavy GPU load.
