# Analysis: Add ability to duplicate row with all panels

> Add a feature that lets users duplicate an entire dashboard row with all its panels.

## Why It Died

The original request stalled because Grafana lacked a unified row abstraction, making duplication complex. The UI code for rows was tightly coupled with panel rendering, preventing a simple copy operation. Additionally, the core team had limited bandwidth to refactor dashboard internals for this feature.

## Why 2026 Changes Everything

Grafana 10 introduced a robust panel library and a declarative dashboard API that expose row and panel definitions as first‑class objects. The Go 1.22 release added generics, simplifying deep copy logic for nested structs. These advancements together remove the technical barriers that existed in 2018.

## Modern Architecture

Implement a RowDuplicationService that receives a dashboard ID and row index, retrieves the Row struct via the dashboard API, and creates a deep copy using Go generics. The service will invoke the existing PanelService to clone each Panel, preserving configuration and datasource references. Updated UI components will call this service through a new REST endpoint, returning the new row ID. Tests will cover serialization round‑trips and UI integration. Documentation will be added to the dashboard provisioning guide, and the feature flag will be introduced for gradual rollout.
