# Proof of Concept: Support multiple formatters for a single file

**Language:** typescript
**Estimated run time:** < 5 minutes

## Prerequisites

- Node.js 20+
- Optional: `npm install` if you add a package.json

## How to Run

```bash
npx --yes ts-node main.ts
```

## What This Demonstrates

VS Code should allow configuring multiple formatters per file to run sequentially on save.
