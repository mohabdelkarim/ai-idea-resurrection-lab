# Proof of Concept: Better error checking and messages for beginners

**Language:** typescript
**Estimated run time:** < 5 minutes

## Prerequisites

- Node.js 20+
- Optional: `npm install` if you add a package.json

## How to Run

```bash
npx --yes ts-node main.ts
```

## What This Demonstrates

Introduce structured compile-time diagnostics to provide clearer, context‑rich error messages for Svelte beginners.
