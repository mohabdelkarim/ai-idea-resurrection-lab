# Proof of Concept: Aastro preview doesn't respect vite preview allowedHostnames in astro config

**Language:** typescript
**Estimated run time:** < 5 minutes

## Prerequisites

- Node.js 20+
- Optional: `npm install` if you add a package.json

## How to Run

```bash
npx --yes ts-node main.ts
```

## What This Demonstrates

Astro preview should honor Vite's allowedHosts setting defined in the Astro configuration file.
