# Proof of Concept: Make React resilient to DOM mutations from Google Translate

**Language:** typescript
**Estimated run time:** < 5 minutes

## Prerequisites

- Node.js 20+
- Optional: `npm install` if you add a package.json

## How to Run

```bash
npx --yes ts-node main.ts
```

## What This Demonstrates

React should gracefully handle DOM mutations introduced by Google Translate without throwing errors.
