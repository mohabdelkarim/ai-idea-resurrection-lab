# Analysis: Setting container hostname to `service_name-xx` instead of container-id

> Docker Compose can optionally set each container's hostname to its service name with instance index.

**Why it will work now:** Docker Engine 24.0 introduced stable --hostname flag propagation, enabling custom hostname patterns in Compose.

## Why It Died

The feature required exposing a hostname template in the Compose file schema, which was not supported by the existing parser. At the time, Docker Engine lacked a stable API to enforce custom hostnames per container, limiting implementation feasibility. The core maintainers prioritized networking and volume features, leaving limited bandwidth for this enhancement. Additionally, the community did not rally enough interest to push the change forward.

## Why 2026 Changes Everything

Docker Engine 24.0 introduced a stable --hostname flag that can be programmatically set per container, aligning with Compose's service definitions. Compose v2.20 added support for a hostname field in the service configuration, enabling explicit hostname assignment. The Go SDK for Docker now provides first‑class functions to retrieve and set container hostnames during composition. These advances remove the previous API gaps and make the feature technically viable.

## Modern Architecture

Introduce a new optional field `hostname_template` in the service struct of the Compose schema, accepting patterns like "{{service}}-{{index}}". Extend the YAML parser to validate and store this template, defaulting to the existing behavior when omitted. During the project generation phase, resolve the template using the service name and instance index, then pass the resulting hostname to the Docker Engine via the updated Go SDK's ContainerCreate options. Ensure the CLI flag `--hostname-template` overrides the file setting for flexibility. Add unit tests covering template parsing, edge cases, and integration tests with Docker Engine 24.0 to verify correct hostname assignment. Update documentation to describe the new field and flag, and provide examples.
