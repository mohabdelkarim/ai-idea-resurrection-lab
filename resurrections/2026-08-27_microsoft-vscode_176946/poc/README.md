# Proof of Concept: Exclude files or directories from editor.formatOnSave

**Language:** typescript
**Estimated run time:** < 5 minutes

## Prerequisites

- Node.js 20+
- Optional: `npm install` if you add a package.json

## How to Run

```bash
npx --yes ts-node main.ts
```

## What This Demonstrates

VSCode should allow users to exclude specific files or directories from the editor.formatOnSave operation.
