## Why It Died

The Express maintainers were hesitant to introduce breaking changes in a major version without extensive testing across all supported Node.js releases. Community bandwidth was limited, and contributors prioritized feature work over refactoring core dependencies. Removing these packages risked subtle compatibility regressions, especially for older Node versions still in use. Additionally, the lack of a dedicated champion to drive the cleanup meant the effort stalled. Finally, the repository's focus shifted to security patches, leaving the dependency removal unaddressed.

## Why 2026 Changes Everything

Node.js 14 LTS and later provide stable, built‑in implementations for HTTP methods, path utilities, and buffer handling, eliminating the need for external shims. Modern ESM support in Node.js 16+ allows direct import of core modules without CommonJS interop hacks. The TypeScript ecosystem now offers comprehensive type definitions for Node's core APIs, simplifying migration. Express's recent move to a TypeScript codebase enables safer refactoring of internal utilities. These concrete advancements collectively make the dependency removal feasible today.

## Modern Architecture

Introduce a core utilities module that re‑exports Node.js built‑ins such as http.METHODS, path.isAbsolute, and Buffer, providing a single import surface for the framework. Replace the 'methods' package with a lazy‑loaded wrapper around http.METHODS, converting entries to lowercase at runtime. Substitute 'path-is-absolute' calls with direct path.isAbsolute usage throughout the routing layer. Remove 'safe-buffer' by adopting Buffer.from and Buffer.alloc directly in all middleware. Eliminate 'setprototypeof' by using Object.setPrototypeOf in the request prototype chain, guarded by a runtime check for older Node versions. Finally, replace 'utils-merge' with object spread syntax in configuration merging, adding TypeScript overloads to preserve type safety. Ensure backward compatibility by providing a shim module that conditionally loads the old packages when running on Node versions prior to 14, controlled via a feature flag.
