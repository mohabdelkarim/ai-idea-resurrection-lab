# Proof of Concept: Allow to place tabs at the bottom

**Language:** typescript
**Estimated run time:** < 5 minutes

## Prerequisites

- Node.js 20+
- Optional: `npm install` if you add a package.json

## How to Run

```bash
npx --yes ts-node main.ts
```

## What This Demonstrates

VSCode should provide a setting to position editor tabs at the bottom of the workbench.
